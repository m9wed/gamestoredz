# GameStore — boutique gaming

Site de démonstration responsive créé en HTML, CSS et JavaScript, sans framework ni base de données.

## Lancer le site
1. Décompressez `gamestore.zip`.
2. Ouvrez le dossier `gamestore`.
3. Double-cliquez sur `index.html` pour l'ouvrir dans votre navigateur.

Pour une meilleure expérience de développement, vous pouvez ouvrir le dossier dans Visual Studio Code et utiliser l'extension Live Server.

## Fonctionnalités
- Catalogue de produits et prix en dinars algériens (prix fictifs à personnaliser)
- Recherche de produits
- Filtres par catégorie
- Panier avec quantités, suppression et calcul du total
- Panier sauvegardé localement dans le navigateur
- Mise en page adaptée aux téléphones et ordinateurs

## Personnalisation
- Produits et prix : `js/script.js`, dans le tableau `products`
- Couleurs et mise en page : `css/style.css`
- Textes et sections : `index.html`

## Important
Ceci est un prototype côté navigateur. Il n'y a pas de compte client, de base de données, de paiement réel ni d'envoi de commande au vendeur. Avant une vraie mise en vente, il faudra ajouter un backend sécurisé, un processus de commande et une méthode de paiement/livraison adaptée. Les prix et les noms de produits sont des exemples : remplacez-les par vos offres réelles et vérifiez les droits de revente des produits numériques.
